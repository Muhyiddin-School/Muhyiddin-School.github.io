# Muhyiddin School Website

## Website management

Open `MUHYIDDIN_WEBSITE_MANAGER_TOOL` and double-click `Launch Website Manager.bat` to manage gallery albums, homepage updates, and bilingual Forms, Documents, and Policies sections. The manager makes timestamped HTML backups and writes activity logs inside its folder. See the tool's `README.txt` for details.
